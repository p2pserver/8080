Blututor standalone landing page (HTML/CSS/JavaScript)

Files:
- index.html: page structure and content
- styles.css: responsive layout and visual styles
- script.js: mobile navigation and demo/toast interactions
- assets/images/: hero, student studying, and parent testimonial images

To preview, extract the folder and open index.html in a browser. Keep the assets folder beside index.html. The Live Demo and Become a Tutor buttons currently display placeholder messages; connect them to the relevant WordPress/BluTutor forms before production.
