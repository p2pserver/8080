# Blututor WordPress Theme v1.4.0

This folder documents the updated Blututor WordPress theme prepared on 2026-10-15.

## What's fixed
- White page background.
- Hero image has no decorative sketches, text overlays, or floating tutor card.
- Support section uses a balanced two-column grid and normal document flow to prevent skew and overlapping text.
- Parent testimonial portrait has fixed dimensions, a circular crop, and `object-fit: cover`.
- Responsive desktop/mobile layout and full-width footer are included.

## Full installable package
The installable ZIP contains the PHP templates, stylesheet, JavaScript, README, and three local image assets. In this session it is available as **blututor-wordpress-theme-v1-4.zip**. GitHub's connected write tools support UTF-8 text files but do not provide a binary-file upload operation, so the ZIP and its local image binaries could not be committed directly through this connection.

## Install
In WordPress Admin, use **Appearance → Themes → Add New Theme → Upload Theme**, select `blututor-wordpress-theme-v1-4.zip`, install, and activate.

## Important
The CTA buttons are currently placeholders. Connect student intake, tutor applications, scheduling, messaging, and payments to BluTutor Core before production use. Images inside the ZIP are crops from the supplied mockup; use original photographs if available for best quality.
